# Pinocchio本地示例项目设计文档

## 项目概述
本项目是Pinocchio机器人动力学库的本地化示例集合，旨在提供一套完整、可运行、文档齐全的Pinocchio学习和参考示例。

## 项目架构设计

### 2. 核心组件设计

#### 2.1 配置管理
- 统一使用`config/examples_config.json`管理所有示例元数据
- 包含环境配置、示例分类、运行参数、依赖信息等
- 支持启用/禁用示例，灵活配置运行策略

#### 2.2 脚本架构
采用分层设计，各脚本职责明确：
- **依赖检查层**：`check_dependencies.py`自动检测系统和Python依赖
- **编译层**：`build_cpp_examples.sh`支持批量增量编译C++示例
- **运行控制层**：`run_all_examples.sh`支持多模式运行、超时控制、并行执行
- **报告层**：`generate_report.py`生成结构化测试报告，支持Markdown和HTML格式

#### 2.3 文档体系
采用标准化文档结构，每个示例文档包含：
1. 原理概述（算法理论、应用场景）
2. 功能说明（输入输出、特性介绍）
3. 依赖要求（版本、安装方法）
4. 使用方法（编译、运行命令）
5. 代码解析（关键代码、API说明）
6. 运行结果（截图、结果分析）
7. 扩展应用（扩展方向、参考资料）

### 3. 示例筛选策略
根据无GPU、无外部可视化库的环境特点，筛选标准：
- ✅ 保留核心算法类示例（运动学、动力学、碰撞检测、自动微分）
- ✅ 保留基于matplotlib的2D可视化示例
- ❌ 排除依赖meshcat、gepetto-viewer等3D可视化库的示例
- ❌ 排除依赖casadi的最优控制示例
- ❌ 排除需要ROS/GPU环境的示例

### 4. 技术规范

#### 4.1 代码规范
- Python示例遵循PEP8规范
- C++示例遵循C++17标准
- 关键代码添加注释说明
- 移除不支持的可视化相关代码，保留核心算法逻辑

#### 4.2 文档规范
- 采用GFM Markdown格式
- 文件名与示例程序名保持一致
- 使用mermaid绘制流程图和原理图
- 文档中注明对应Pinocchio版本和依赖版本

#### 4.3 测试规范
- 每个示例单独测试，记录运行状态、性能指标
- 建立基准测试结果库，支持回归测试
- 输出结果与理论值比对，误差在允许范围内视为通过

- **依赖缺失**：在文档中明确标注可选依赖，提供安装说明
